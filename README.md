## Mageluim - https://mageluim.vercel.app/

# Технологии: Next.js, TypeScript, Zustand

Mageluim - коллекционная карточная игра c элементами Gachapon.
Игроку предстоит призывать карты навыков различных стихий, составлять из них боевую колоду, вступать в бой с противниками, которые также обладают различными навыками.
Также в игре есть артефакты, которые усиливают героя. В магазине игрок может купить необходимые ему карты навыков и артефакты за золото.
На старте игроку нужно выбрать героя - одного из магов, каждый из них обладет различными свойствами.
После выбора героя, игрок получает несколько камней для призыва карт навыков, далее ресусры для призыва можно получить при победе противников на каждом этаже.
